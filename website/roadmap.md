# A sequence for reviewing direction

This roadmap is a presentation scaffold. It deliberately avoids dates, version promises, and capability-state assignments.

<RoadmapTimeline />

## Single-node focus

The visual narrative starts with one inspectable runtime node: explicit Profile identity, bounded execution, externalized state, and evidence-aware interfaces.

## Long-term direction

Distributed agent collaboration is presented only as a long-term direction. It is not represented as a current capability and does not receive an availability badge.
