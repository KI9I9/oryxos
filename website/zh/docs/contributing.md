## Overview / 概述

参与贡献应从源码仓库、当前 Issue、项目治理约束和清晰的问题说明开始。

## Intended design / 预期设计

正式流程应说明范围、测试、代码质量、文档影响、评审预期，以及能力声明如何与证据保持一致。
