# Design principles

<PrototypeDocShell eyebrow="CONCEPT / PRINCIPLES" summary="A compact visual system for the constraints that shape OryxOS." />

## Overview

The prototype organizes the project around explicit identity, understandable execution, bounded integrations, externalized state, self-hosted operation, and evidence-backed public claims.

## Intended design

One YAML Profile completely defines an Agent. A Profile may declare or reference a Skill that supplies behavioral instructions and is loaded as prompt context. Skill is not presented as an executable Tool.
