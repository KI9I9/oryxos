# What is OryxOS?

<PrototypeDocShell eyebrow="CONCEPT / POSITIONING" summary="A visual draft for explaining an Agent OS as an operating model rather than a chatbot wrapper." />

## Overview

OryxOS explores a Java-native, self-hosted runtime foundation for agents. This prototype concentrates on the information shape of one runtime node and does not claim production readiness.

## Intended design

The intended model brings identity, orchestration, provider access, bounded tools, externalized state, and inspectable interfaces into explicit system boundaries.
