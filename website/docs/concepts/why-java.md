# Why Java?

<PrototypeDocShell eyebrow="CONCEPT / PLATFORM" summary="A page form for connecting Java runtime qualities to an inspectable Agent OS kernel." />

## Overview

Java 21 offers a familiar operational ecosystem, strong tooling, explicit types, and a concurrency model suitable for exploring understandable runtime boundaries.

## Intended design

The visual narrative emphasizes maintainable server-side components, virtual-thread-friendly blocking flows, conventional observability, and deployment on infrastructure the operator controls.
